# 수능 수학 풀이 코치

문제 사진과 막힌 지점을 입력하면 정답을 바로 보여 주기보다, 학생이 지금 해야 할 **다음 한 걸음**을 안내하는 수학 코칭 웹앱입니다.

이 앱은 고3 미적분 학습 부진에서 출발했습니다. 치환적분, 정적분, 급수와 정적분의 관계처럼 여러 개념이 겹치는 단원에서는 학생이 계산을 몰라서만 막히는 것이 아닙니다. 긴 수식 앞에서 어디를 먼저 봐야 할지 놓치고, 해설을 눈으로만 따라가며, 같은 실수를 반복하는 문제가 함께 나타납니다.

따라서 이 앱의 목표는 완성 풀이를 대신 제공하는 것이 아니라, 학생이 멈춘 자리에서 다시 한 줄을 써 보게 만드는 것입니다.

## 1. 개발 목적

이 프로젝트는 수학 학습 부진을 단순히 “문제를 많이 풀면 해결되는 문제”로 보지 않고, 풀이 과정에서 학생이 실제로 막히는 지점을 줄이는 방향으로 설계했습니다.

핵심 문제의식은 다음과 같습니다.

- 복잡한 수식이 나오면 풀이 시작점을 잡지 못한다.
- 정답 해설은 이해한 것 같지만, 스스로 다음 줄을 쓰지 못한다.
- 수식과 그래프, 도형의 의미를 연결하지 못한다.
- 반복되는 실수가 기록되지 않아 약점이 누적된다.

## 2. 설계 방향

앱의 중심은 정답 출력이 아니라 코칭 흐름입니다.

```text
문제 인식
→ 막힌 지점 진단
→ 다음 한 걸음 제시
→ 단계별 힌트
→ 필요한 경우 그래프 시각화
→ 실수 유형 기록
```

특히 `next_step`은 한 번에 하나의 행동만 요구하도록 설계했습니다. 예를 들어 “증감표를 완성해 봐”가 아니라 “대표값 하나를 넣어 부호만 확인해 볼래?”처럼 작게 나눕니다.

## 3. SW 구조

| 파일 | 역할 | 설계 의도 |
|---|---|---|
| `index.html` | 화면 뼈대 | 문제 입력, 결과, 그래프, 이어가기 입력칸을 배치합니다. |
| `style.css` | 화면 디자인 | 모바일과 데스크톱에서 읽기 쉬운 학습 UI를 만듭니다. |
| `app.js` | 브라우저 로직 | 사진 압축, 요청, 코칭 렌더링, 그래프, 실수 노트, PDF 저장을 처리합니다. |
| `api/coach.js` | 서버리스 API | Gemini API 키를 숨기고, 튜터 기준과 그래프 결정 기준을 적용합니다. |

API 키는 브라우저 코드에 넣지 않습니다. Vercel 환경변수 `GEMINI_API_KEY`로만 설정하도록 설계했습니다.

## 4. 핵심 구현

- 문제 사진을 브라우저에서 압축해 서버로 전송합니다.
- AI 응답을 JSON 구조로 고정해 화면이 안정적으로 처리하게 했습니다.
- 수식은 KaTeX로 렌더링합니다.
- 그래프는 Plotly로 2D/3D 시각화합니다.
- 실수 유형은 같은 기기의 `localStorage`에 저장합니다.
- 질문 횟수 제한, 이미지 크기 제한, 응답 실패 처리 등 기본 안정성 처리를 넣었습니다.

## 5. 그래프 설계

그래프는 장식이 아니라, 학생이 지금 봐야 할 수학적 관계를 표현하기 위한 장치입니다.

그래프 선택은 먼저 `next_step`을 정한 뒤, 그 한 걸음을 돕는 장면이 필요한지 판단하는 방식으로 설계했습니다.

| 상황 | 선택 |
|---|---|
| 함수의 변화, 교점, 위아래, 넓이 | `function2d` |
| 점, 선분, 삼각형, 원, 접선, 보조선 | `geometry2d` |
| 원, 타원, 쌍곡선, 음함수 자체 | `implicit2d` |
| 회전체, 공간좌표, 3D 곡면 | 3D 계열 |
| 경우의 수, 단순 대입, 계산만 남은 상황 | `none` |

중요한 기준은 정답 유출 방지입니다. 예를 들어 극값 문제에서 원래 함수 위에 점을 찍으면 그 y값이 답이 될 수 있으므로, 도함수 그래프에서 후보 위치만 보여 주도록 했습니다.

## 7. 배포 요약

1. 이 폴더 안의 파일을 GitHub 저장소에 올립니다.
2. Vercel에서 해당 저장소를 Import합니다.
3. Vercel 환경변수에 `GEMINI_API_KEY`를 추가합니다.
4. Deploy 후 생성된 주소에서 문제 사진으로 테스트합니다.

자세한 배포 절차는 `사용_가이드.pdf`를 따릅니다.

## 8. 한계와 개선 방향

- 사진이 흐리거나 잘리면 문제를 잘못 읽을 수 있습니다.
- Gemini 무료 사용량을 다 쓰면 잠시 사용할 수 없습니다.
- 실수 기록은 같은 기기와 같은 브라우저 안에만 저장됩니다.
- 장기 오답 관리가 필요하면 로그인과 데이터베이스를 추가할 수 있습니다.
- 선생님용 관리 화면이나 반별 통계는 후속 확장 기능으로 남겨 두었습니다.

## 요약

이 앱은 수능 수학 학습에서 나타나는 수식 불안, 수동적 해설 학습, 오답 누적 문제를 줄이기 위해 설계한 웹앱입니다. 정답보다 다음 한 걸음을 먼저 제시하고, 필요한 경우 수식·그래프·오답 기록을 연결해 학생이 다시 직접 풀이를 이어 가도록 돕습니다.
